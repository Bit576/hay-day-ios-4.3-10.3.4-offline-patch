# [OFFLINE PATCH] Hay Day v1.18.166

![Hay Day screenshot](image.png)

This project is for people who want to play an older version of Hay Day on a legacy iOS device. It is a non-commercial fan project and is not affiliated with or endorsed by Supercell.

## About

This offline patch is for Hay Day v1.18.166 and is compatible with iOS 4.3–10.3.4. It allows the game to launch without an internet connection, so no private server setup is required.

The app has been changed as little as possible; only a few lines of code were removed. Most offline features should work, but online features such as selling items and adding friends are unavailable.

## Compatibility

- Game version: 1.18.166
- iOS: 4.3–10.3.4
- Device: legacy iOS devices

## Known limitations

The game has not been fully tested, so bugs or other issues may occur. If you encounter a significant issue, please contact me.
